# Custom shot requests

One spec per request, named `cNN-<demo>-<what>.json`. Renders go to `Videos\CS2 Renders\Custom Shots\`
(graded, no black bars, plus an 8-bit copy, per the user's CapCut delivery rule).

| # | Demo | Request | Spec |
|---|---|---|---|
| C01 | A13 | Static shot ~10 s, still camera, high FOV (100), from the spot the user moved to at the end of the demo (0:07-0:17) | c01-a13-static-wide.json |
| C02 | A13 | Same angle and window, camera moving back very slowly (70 u over 10 s; a wall stops it at ~80 u) | c02-a13-slow-pullback.json |
